# Module 0: Set up the app

Get the starter app running, make your own copy, deploy it, and make one small
change. Step-by-step instructions are in `instructions.md`; the tests are in
`tests/`.

## Acceptance criteria

- **AC-0.1** The home page shows the Week 0 line.
- **AC-0.2** You changed the Week 0 line in `app/page.tsx` to your own words.

AC-0.2 fails until you do the Module 0 task, so a fresh clone shows one passing
and one failing criterion.
